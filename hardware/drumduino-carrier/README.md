# DrumDuino Carrier v2.0 (บอร์ดฐานสำหรับ Mega 2560 PRO)

แผ่น PCB 2 ชั้น ขนาด 140 × 120 มม. ใช้เป็นบอร์ดฐานของ **Mega 2560 PRO (Embed)** ของ RobotDyn หรือรุ่นที่ขาเหมือนกัน
บอร์ด Mega PRO เสียบลงบนเฮดเดอร์ตัวเมียที่บัดกรีไว้บนแผ่นนี้

- **แจ็ค 6.35 มม. 16 ช่องบนแผ่น:** ขอบบน 8 ช่อง ขอบล่าง 8 ช่อง หัวแจ็คยื่นออกนอกขอบแผ่นเพื่อลอดรูของกล่อง
- **วงจรป้องกันทุกช่อง:** ตัวต้านทาน 1 MΩ และซีเนอร์ 5.1V ต่อลง GND
- **ช่อง A15 สำหรับแป้นไฮแฮท:** TIP = ขากลางของ pot, RING = VCC, SLEEVE = GND
- **ช่องไฟ DC 5.5 × 2.1 มม.:** ไฟผ่านไดโอด 1N5819 กันต่อขั้วกลับ แล้วเข้าขา VIN ใช้อแดปเตอร์ 9V แบบขั้วบวกอยู่ตรงกลาง
  ถ้าเสียบแค่ USB บอร์ดก็ทำงานได้

เปิดโปรเจกต์ด้วย KiCad 7 ขึ้นไป โดยเปิดไฟล์ `drumduino-carrier.kicad_pro`
โมเดล 3D ทุกชิ้นอยู่ในโฟลเดอร์ `3dmodels` ของโปรเจกต์ กด Alt+3 ใน PCB Editor เพื่อดูภาพ 3D

## การต่อสาย
- **แป้นทั่วไป:** ใช้สายกีตาร์โมโน 6.35 มม. ตัวผู้–ตัวผู้ ต่อจากแจ็คของ piezo มาที่แจ็คบนแผ่น
  RING ของแจ็คบนแผ่นไม่ได้ต่อใช้งาน สายโมโนเสียบได้ปกติ
- **แป้นไฮแฮท:** ใช้สายสเตริโอ (TRS) และต่อ pot 10 kΩ ดังนี้: TIP = ขากลาง, RING = ขาข้างหนึ่ง, SLEEVE = ขาอีกข้าง
  **อย่าเสียบสายโมโนเข้าช่อง A15** เพราะสายโมโนจะต่อ RING (VCC) ลง GND
- **ถ้าจะตีขอบ:** ใช้ piezo แผ่นที่ 2 เสียบเข้าอีกช่องหนึ่ง เช่น A8 สำหรับขอบสแนร์ หรือ A9 สำหรับระฆังไรด์

## ช่องที่ตั้งไว้ (พิมพ์ไว้บนแผ่น)
| ขอบบน | | ขอบล่าง | |
|---|---|---|---|
| A0 | Crash | A1 | Hi-hat |
| A2 | Snare | A3 | Kick |
| A4 | Tom 1 | A5 | Tom 2 |
| A6 | Floor | A7 | Ride |
| A8 | ขอบสแนร์ | A9 | ระฆังไรด์ |
| A10, A12, A14 | ว่าง | A11, A13 | ว่าง |
| | | A15 | แป้นไฮแฮท |

ช่อง A0–A7 ตรงกับค่าเริ่มต้นของแอป DrumDuino อยู่แล้ว
ส่วนขอบสแนร์, ระฆังไรด์ และแป้นไฮแฮท ให้ไปตั้งในหน้า **ฮาร์ดแวร์** ของแอป

## ข้อควรระวัง
- พอร์ต USB ของบอร์ด Mega PRO อยู่ขอบซ้ายของแผ่น ให้เว้นช่องที่กล่องไว้เสียบสาย
- ก่อนสั่งทำแผ่น ให้เทียบขาของบอร์ด Mega PRO ที่ซื้อมาว่าตรงกับลายบนแผ่น:
  แถวบน A0, A2 … A14 / แถวล่าง A1, A3 … A15 และมุมซ้ายล่าง VIN, GND, VCC
- แผ่นใหญ่กว่า 100 × 100 มม. ค่าทำแผ่นที่ JLCPCB จะแพงกว่าราคาต่ำสุดเล็กน้อย
- โมเดล 3D ของบอร์ด Mega PRO และแจ็ค Rean เป็นรูปทรงคร่าว ๆ ที่ทำเอง ไว้ดูตำแหน่งและความสูงเท่านั้น
  ส่วนชิ้นอื่นเป็นโมเดลทางการของ KiCad 7

ไฟล์ทั้งหมดในโฟลเดอร์นี้สร้างจาก `../gen_carrier.py` ถ้าแก้ตำแหน่งหรือจำนวนช่อง ให้แก้สคริปต์แล้วรันใหม่
