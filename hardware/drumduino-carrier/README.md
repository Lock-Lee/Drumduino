# DrumDuino Carrier v1.0 (บอร์ดสำหรับ Mega 2560 PRO)

แผ่น PCB 2 ชั้น ขนาด 100 × 100 มม. ใช้เสียบบอร์ด **Mega 2560 PRO (Embed)** ของ RobotDyn หรือรุ่นที่ขาเหมือนกัน
มีอินพุตสำหรับ piezo 16 ช่อง (A0–A15) ทุกช่องมีวงจรป้องกัน (ตัวต้านทาน 1 MΩ และซีเนอร์ 5.1V)
ช่อง A15 ใช้กับแป้นไฮแฮทที่เป็น pot และมีไฟ VCC ออกที่ขั้วต่อด้วย

เปิดโปรเจกต์ด้วย KiCad 7 ขึ้นไป โดยเปิดไฟล์ `drumduino-carrier.kicad_pro`

## ไฟล์สำหรับสั่งทำแผ่น
- `fab/drumduino-carrier-gerbers-JLCPCB.zip` อัปโหลดไฟล์นี้ที่ jlcpcb.com ได้เลย ใช้ค่ามาตรฐานได้ทั้งหมด: 2 layers, 1.6 mm, HASL, สีอะไรก็ได้
- `fab/drumduino-carrier-schematic.pdf` วงจรสำหรับพิมพ์ดู

|---|---|---|---|
| U1 | 1 | Mega 2560 PRO (Embed) CH340 | ใส่บนเฮดเดอร์ตัวเมีย |
| – | 1 | เฮดเดอร์ตัวเมีย 2×16 ขา 2.54 มม. (หรือ 1×16 จำนวน 2 แถว) | ตรงแถว A0–A15 / D32–D47 |
| – | 1 | เฮดเดอร์ตัวเมีย 2×3 ขา 2.54 มม. | ตรง VIN / GND / VCC |
| J1–J15 | 15 | เทอร์มินอลบล็อก 2 ขา ระยะ 5.08 มม. (KF301-2P / DG301) | ขา 1 (แผ่นเหลี่ยม) = TIP, ขา 2 = GND |
| J16 | 1 | เทอร์มินอลบล็อก 3 ขา ระยะ 5.08 มม. | แป้นไฮแฮท: 1 = wiper, 2 = VCC, 3 = GND |
| R1–R16 | 16 | ตัวต้านทาน 1 MΩ 1/4W | ใส่แบบตั้ง |
| D1–D16 | 16 | ซีเนอร์ 1N4733A (5.1V 1W) | ใส่แบบตั้ง **ด้านที่มีแถบ (K) ลงแผ่นสี่เหลี่ยม** |
| H1–H4 | 4 | เสารอง M3 | ใช้ยึดกับกล่อง |
| – | 15 + 1 | แจ็ค 6.35 มม. แบบติดแผง (โมโน 15 ตัว, สเตริโอ 1 ตัวสำหรับแป้นไฮแฮท) | ติดที่กล่อง แล้วเดินสายมาที่เทอร์มินอล |

## การต่อสาย
- **แจ็คโมโนของ piezo:** ขา TIP ต่อเข้าขา 1 ของเทอร์มินอล และขา SLEEVE (กราวด์) ต่อเข้าขา 2
- **แป้นไฮแฮท** (pot 10 kΩ กับแจ็คสเตริโอ): TIP (ขากลางของ pot) ต่อเข้า J16 ขา 1, RING ต่อเข้าขา 2 (VCC), SLEEVE ต่อเข้าขา 3 (GND)
- **ถ้าจะตีขอบได้:** ใช้ piezo แผ่นที่ 2 ต่อเข้าอีกช่องหนึ่ง เช่น A8 สำหรับขอบสแนร์ หรือ A9 สำหรับระฆังของไรด์

## ช่องที่ตั้งไว้ (พิมพ์ไว้บนแผ่น)
| ขา | ชิ้นกลอง | ขา | ชิ้นกลอง |
|---|---|---|---|
| A0 | Crash | A8 | ขอบสแนร์ |
| A1 | Hi-hat | A9 | ระฆังไรด์ |
| A2 | Snare | A10–A14 | ว่าง (AUX) |
| A3 | Kick | A15 | แป้นไฮแฮท |
| A4 | Tom 1 | | |
| A5 | Tom 2 | | |
| A6 | Floor | | |
| A7 | Ride | | |

ช่อง A0–A7 ตรงกับค่าเริ่มต้นของแอป DrumDuino อยู่แล้ว
ส่วนขอบสแนร์, ระฆังไรด์ และแป้นไฮแฮท ให้ไปตั้งในหน้า **ฮาร์ดแวร์** ของแอป โดยเลือกขาขอบหรือขาแป้นของชิ้นกลองนั้น

## ข้อควรระวัง
- พอร์ต USB ของบอร์ด Mega PRO อยู่ด้านซ้ายของแผ่น ให้เว้นช่องที่กล่องไว้เสียบสาย
- ตรวจขาของบอร์ด Mega PRO ที่ซื้อมาว่าตรงกับลายบนแผ่น: แถวบน A0, A2 … A14 / แถวล่าง A1, A3 … A15 และมุมซ้ายล่าง VIN, GND, VCC
  บอร์ดของผู้ผลิตบางรายอาจขาไม่ตรง ให้เทียบก่อนสั่งทำแผ่น
- ถ้าบอร์ดตั้งไฟ VCC ไว้ที่ 3.3V แป้นไฮแฮทก็ยังใช้ได้ ให้ปรับค่าตอนเหยียบสุดและปล่อยสุดในแอป

ไฟล์ทั้งหมดในโฟลเดอร์นี้สร้างจาก `../gen_carrier.py` ถ้าแก้ตำแหน่งหรือจำนวนช่อง ให้แก้สคริปต์แล้วรันใหม่
